# 예외 구조대

분명히 썼는데 0바이트? — 파이썬 예외 처리와 안전한 파일 쓰기를 손으로 체험하는 앱입니다. 구문 에러와 예외의 차이, 자주 만나는 예외 6종과 이름 맞히기, 이상한 센서 값을 건너뛰는 try·except, 한 줄씩 따라가는 try·except·else·finally 흐름, except 순서, raise와 사용자 정의 예외(OverheatingError), except: pass와 이름 없는 except의 위험, r·w·a 파일 모드 실험실, 인코딩, 8,192바이트 버퍼와 강제 종료로 사라지는 데이터, with 문, CSV의 newline="", 망가진 줄을 건너뛰는 로그 분석기까지 담았습니다. 파이썬 07 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 예외: 0바이트 사건 접수, 구문 에러 vs 예외, 예외 6종과 오류 메시지, 예외 이름 맞히기, 센서 스트림(try 없이 / try·except로)
- ② try 흐름: 한 줄씩 실행하는 try·except·else·finally(except 안의 또 다른 예외 포함), 퀴즈 ①, except 순서, raise, except: pass, 중지 키를 삼키는 except:
- ③ 파일 모드: r·w·a·b 표, 파일 실험실(1년치 기록·파일 없음), 퀴즈 ②, 인코딩
- ④ 버퍼·with: 버퍼·디스크 시뮬레이터(close·예외·강제 종료), with 문, CSV 빈 줄 문제, 강건한 로그 분석기, 세 줄 정리, 생각해 볼 질문

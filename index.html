🔒 with 문 = try·finally를 대신 써 주는 것

with open("t.txt", "w") as g: g.write("abc") 1 / 0 # 블록 안에서 예외! # ↓ 블록 밖에서 확인 print(g.closed, os.path.getsize("t.txt"))
ZeroDivisionError: division by zero (except로 잡은 뒤 확인) True 3 ← 닫혀 있고, 3바이트 저장됨
# with 문이 사실상 해 주는 일 f = open("t.txt", "w") # __enter__ try: f.write("abc"); 1 / 0 finally: f.close() # __exit__ — 예외가 나도 실행
파일을 열 때는 with 문 — 오늘의 황금률입니다.

📌 세 줄 정리

  1. 구문 에러는 고치고, 예외는 try·except로 대비하며, 구체적인 예외를 먼저 잡는다.
  2. else는 성공했을 때만, finally는 언제나 실행되고, 예외를 숨기는 pass는 피한다.
  3. w는 지우고 a는 잇는다. 파일은 with 문으로 열어 버퍼까지 안전하게 닫는다.
